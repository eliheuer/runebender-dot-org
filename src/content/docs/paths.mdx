<DocSection title="Clean Up">

<table>
  <caption>Path menu, cleanup</caption>
  <tbody>
    <tr><th>Tidy Up Paths</th><td><code>Cmd+Shift+T</code>. Drops zero-length segments.</td></tr>
    <tr><th>Add Extremes</th><td>Inserts points at the extremes of each curve.</td></tr>
    <tr><th>Round Coordinates</th><td>Snaps every coordinate to whole units.</td></tr>
    <tr><th>Correct Path Direction</th><td><code>Cmd+Shift+R</code>. Outer contours counter-clockwise, holes clockwise, by containment depth.</td></tr>
    <tr><th>Reverse Contours</th><td><code>Cmd+Alt+Shift+R</code>. Flip direction by hand.</td></tr>
    <tr><th>Set Start Point</th><td>Make the selected point the first point of its contour.</td></tr>
  </tbody>
</table>

<Callout>
  Run Correct Path Direction, Set Start Point, and Tidy Up Paths
  before blaming interpolation. Between them they cause most
  incompatible glyphs. See <a href="/docs/masters.html">Masters and
  Interpolation</a>.
</Callout>

</DocSection>

<DocSection title="Combine">

<table>
  <caption>Boolean operations</caption>
  <tbody>
    <tr><th>Remove Overlap</th><td><code>Cmd+Shift+O</code>. Merges overlapping contours into one outline.</td></tr>
    <tr><th>Union</th><td>Adds everything together.</td></tr>
    <tr><th>Subtract</th><td>Cuts the rest out of the first contour.</td></tr>
    <tr><th>Intersect</th><td>Keeps only the area they share.</td></tr>
    <tr><th>Exclude</th><td>Keeps only the area they do not share.</td></tr>
  </tbody>
</table>

Union merges everything; the others apply the first contour against
the rest combined.

</DocSection>

<DocSection title="Filters">

Filters reshape an outline rather than clean it up.

<table>
  <caption>Filter menu</caption>
  <tbody>
    <tr><th>Offset Curve</th><td>Grows or shrinks the outline by a distance.</td></tr>
    <tr><th>Extrude</th><td>Pushes the shape out along a direction.</td></tr>
    <tr><th>Roughen</th><td>Breaks smooth edges into a rougher line.</td></tr>
    <tr><th>Slanter</th><td>Slants the outline, for oblique work.</td></tr>
    <tr><th>Round Corners</th><td>Fillets the selected corners. The size and handle ratio follow the corners already in the glyph.</td></tr>
  </tbody>
</table>

The Filter menu also repeats Add Extremes and Remove Overlap.

The Path Operations section of the right panel holds the values the
filters use: Slant °, Offset ±, Extrude d,° and Roughen s,h,v. Type a
value and press Enter to apply it.

</DocSection>

<DocSection title="Expand Stroke">

Expand Stroke is not in a menu. It is the Stroke width field in the
Path Operations section. It turns each contour into the outline of a
stroke of that width, with round joins and caps.

1. Draw open skeleton paths with the pen tool.
2. Select them, or select nothing to take the whole glyph.
3. Type a weight in Stroke width and press Enter.

You get letterforms from a skeleton, and the skeleton is easy to
redraw at a different weight.

</DocSection>

<DocSection title="Context Menu">

Right-click the canvas for these operations: Add Anchor, Set Start
Point, Round Corners, Reverse Contours, Remove Overlap, Flip
Horizontal, Flip Vertical, Rotate 90, Duplicate, Harmonize, Balance,
Optimize, and Decompose.

Right-click a component for more rows at the top: Edit Component in
Place, Open followed by the base glyph's name (it opens that glyph in
its own tab), and Enable or Disable Automatic Alignment. Right-click a placed image to lock or remove it.

</DocSection>
