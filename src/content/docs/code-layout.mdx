<DocSection title="One Workspace">

Work in [runebender-xilem](https://github.com/eliheuer/runebender-xilem).
The root package, `runebender`, provides the editor and headless subcommands. Its font library is included under `crates/`;
no separate library checkout is needed. The repository's `AGENTS.md` records
build commands and conventions; `DESIGN.md` covers interface changes.

</DocSection>

Xilem views read state. Commands describe complete user actions, shared by
menu items and shortcuts. Reuse theme accessors and design tokens when
changing a view.

</DocSection>

<DocSection title="Font Operations">

The workspace library groups source into six concerns:

<table>
  <caption>Font library modules</caption>
  <tbody>
    <tr><th><code>outline/</code></th><td>Shape editing and curve mathematics.</td></tr>
    <tr><th><code>analysis/</code></th><td>Measurements, curve analysis, and search.</td></tr>
    <tr><th><code>formats/</code></th><td>File formats, import, and metadata keys.</td></tr>
    <tr><th><code>document/</code></th><td>Masters, projects, interpolation, and composites.</td></tr>
    <tr><th><code>text/</code></th><td>Shaping, joining rules, and the text buffer.</td></tr>
    <tr><th><code>ui/</code></th><td>Colors, themes, sidebar data, selection, undo, and viewport state.</td></tr>
  </tbody>
</table>

Each directory's `mod.rs` explains its scope. Operations use norad types and
kurbo geometry. Public items have doc comments; editing operations report
whether or how much they changed.

</DocSection>

<DocSection title="Validation">

Follow [Development](/docs/development.html) for workspace checks. Tests live
beside the code they exercise. Set `RUNEBENDER_TEST_FONTS` for font fixtures.
Check interface changes with matching-size screenshots and native interaction;
headless captures alone cannot verify keyboard, pointer, or browser behavior.

</DocSection>
