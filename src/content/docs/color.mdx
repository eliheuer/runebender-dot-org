<DocSection title="Current State">

The editor has no palette, colour layer, or COLR controls. You cannot
make a colour font in Runebender.

When you save a UFO, Runebender keeps font lib keys that it does not
edit, and it keeps extra UFO layers. Colour data that another tool
wrote with the ufo2ft keys, such as
`com.github.googlei18n.ufo2ft.colorPalettes`, stays in the file.

<Callout>
  Use a different tool to edit colour data. Runebender does not show it.
</Callout>

</DocSection>
