<DocSection title="Role">

Runebender GPUI is the front-end that gets new work first. It is built on the GPUI
framework and on `runebender-core` for font math, text layout, and shaping. The same
code compiles to a native app and to WebAssembly. The browser build at
[/gpui/](/gpui/index.html) is the default launch target on this site.

</DocSection>

<DocSection title="Launch">

- Browser: open [runebender.org/gpui/](/gpui/index.html). The first visit reloads once
  to install a service worker that adds the cross-origin isolation headers the build
  needs. The editor then loads with a bundled demo font.
- Native: clone [eliheuer/runebender-gpui](https://github.com/eliheuer/runebender-gpui)
  and run `cargo install --path . --locked`. The repo README documents the toolchain.

</DocSection>

<DocSection title="What it does">

The feature set tracks Glyphs 4, with a checklist in the repo
([GLYPHS4.md](https://github.com/eliheuer/runebender-gpui/blob/main/GLYPHS4.md)).
Highlights:

- Variable font editing: masters, brace and bracket layers, instances, avar maps,
  higher-order interpolation, and a Show All Masters overlay.
- Arabic and RTL: harfbuzz-class shaping in the edit view, positional-forms matrix,
  mark cloud, cursive attachment, joining QA, and per-language preview
  ([ARABIC-RTL.md](https://github.com/eliheuer/runebender-gpui/blob/main/ARABIC-RTL.md)).
- Components: regular, smart (multi-axis), and corner components.
- Feature code: a fea editor with fea-rs checks, generated kern, mark, mkmk, ccmp,
  positional, and GDEF blocks.
- Import and export: UFO and designspace sources, TTF/OTF import, SVG import and
  export, and Google Fonts-compatible builds through fontc (Cmd-E).
- Color fonts: COLRv0 layers and COLRv1 conversion.

</DocSection>

<DocSection title="Relation to the other versions">

- `runebender-core` is the shared headless library; GPUI is a client of it.
- The Cloud editor at [/cloud/editor/](/cloud/editor/index.html) is the earlier web
  editor. It stays available, but new work lands in GPUI.
- Xilem is the earlier native editor; its manual still documents concepts the two
  editors share.

</DocSection>
