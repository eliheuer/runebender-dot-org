<DocSection title="Widths and Sidebearings">

The Glyph section of the inspector holds the Width, LSB and RSB of the
current glyph. Type a value and the outline or the sidebearing moves.
The metrics card at the bottom of the canvas shows the same three
numbers, and you can type into it too.

You can also drag. With the select tool, the sidebearing edges are
draggable directly, which changes spacing without touching the
outline.

</DocSection>

<DocSection title="Metric Keys">

A metric key derives a sidebearing from another glyph, so a change to
one glyph carries to every glyph that refers to it. The editor has no
field to type a key. It reads the keys that are already in the glyph
lib, for example from a source that came from Glyphs.

<table>
  <caption>Metric key syntax</caption>
  <tbody>
    <tr><th><code>=n</code></th><td>The same sidebearing as glyph <code>n</code>.</td></tr>
    <tr><th><code>=|o</code></th><td>The opposite sidebearing of glyph <code>o</code>. Use it for a mirrored pair.</td></tr>
    <tr><th><code>=n+10</code></th><td>The same, plus ten units.</td></tr>
    <tr><th><code>=n*1.1</code></th><td>The same, scaled.</td></tr>
    <tr><th><code>=50</code></th><td>A constant.</td></tr>
  </tbody>
</table>

Glyph → Update Metrics applies every key in every master. Keys can
chain: if `n` has a key of its own, the passes repeat until nothing
moves, up to five passes.

Metric keys are stored in the lib keys glyphsLib round-trips, so a
source that came from Glyphs keeps its formulas and a source that
leaves Runebender takes them along.

</DocSection>

<DocSection title="Kerning Groups">

A group lets one value cover many pairs. Set the left and right group
of a glyph in the Glyph section of the right panel. Clearing a field
removes the membership.

The Groups section in the grid view shows every group as a shelf with
its members as chips. Click a chip to remove that member. Select
glyphs in the grid, then press + sel to add the whole selection to a
group at once. The field creates a new
group from the selection: `o` makes a first-side group, `|o` a
second-side one.

Groups are written to `groups.plist` for every master, using the
standard `public.kern` prefixes.

</DocSection>

<DocSection title="The Kerning Table">

The Kerning section in the grid view lists the pairs on the active
master. Filter them with the Filter pairs field. To set a pair, type
the First and Second names and the Value, then press Enter. Each
listed pair has a button that deletes it.

Use the text tool to see the result in real words. See
[Text and Shaping](/docs/text.html).

</DocSection>

<DocSection title="Checking Your Work">

The Dimensions section in the grid view measures stems and bars from
the reference glyphs in each master. It shows whether the weights
match across a designspace, rather than the numbers you meant to draw.

The Compare section lists differing advance widths between masters,
along with structural incompatibilities and kerning pair counts.

</DocSection>
