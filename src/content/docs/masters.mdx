<DocSection title="Masters">

Open a `.designspace` file and Runebender opens every master it names.
Open a single `.ufo` and you get one master.

The Masters section of the right panel lists them by name. Click a
row to switch. View → Next Master and View → Previous Master step
through them.

The same section edits the designspace sources. Add source adds an
interpolated source at the axis slider position, with the name in
Source name. Save writes its new UFO.
Apply renames and moves the active source. Up, Down and Remove change
the list, and Undo sources and Redo step back and forward.

View → Show All Masters draws every master at once over the current
glyph.

</DocSection>

<DocSection title="Axes">

The Axes section sits below the Masters section in the editor. It has
one slider per designspace axis. Moving a slider shows the
interpolated result as a ghost over the drawing, so you can see a
weight between two masters while you edit either one.

If the glyph does not interpolate at that position, the section shows
a warning that says why.

</DocSection>

<DocSection title="Compatibility">

Interpolation needs matching outlines: the same number of contours,
the same number of points in each, in the same order, starting at the
same place. When a glyph does not interpolate, that is almost always
why.

<table>
  <caption>The usual fixes</caption>
  <tbody>
    <tr><th>Correct Path Direction</th><td>Outer contours one way, holes the other, by containment depth.</td></tr>
    <tr><th>Set Start Point</th><td>Make each contour start in the same place.</td></tr>
    <tr><th>Tidy Up Paths</th><td>Remove zero-length segments, which differ between masters without being visible.</td></tr>
  </tbody>
</table>

The Compare section in the grid view reports structural
incompatibilities across every master at once, along with glyph
counts, differing advances, kerning pair counts, and vertical metrics
that disagree. Use it before you go hunting glyph by glyph.

</DocSection>

<DocSection title="Reinterpolate">

Glyph → Reinterpolate replaces the current glyph with what the
surrounding masters say it should be at this position. It is the way
back when a glyph has drifted out of step with the rest of the
designspace.

<Callout>
  Reinterpolate overwrites the glyph in the current master. Undo
  brings it back.
</Callout>

</DocSection>

<DocSection title="Smart Components">

A smart component carries its own axes, so one component holds a range
of shapes rather than a single fixed one. See
[Components and Anchors](/docs/components.html).

Interpolation across several axes uses a corner-delta model: the
default shape plus the contribution of each axis corner. One axis
interpolates linearly, and two axes with every corner present
interpolate bilinearly.

</DocSection>

<DocSection title="Masks">

A source can mark contours as masks in the glyph lib. The editor
subtracts a mask from the other contours in the preview. Glyph → Bake
Masks makes the subtraction real in the outlines, so other tools see
the same shape. The editor has no control to mark a contour as a
mask.

</DocSection>
