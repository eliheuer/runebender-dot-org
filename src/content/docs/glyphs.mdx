<DocSection title="Add and Remove">

<table>
  <caption>Glyph menu</caption>
  <tbody>
    <tr><th>New Glyph</th><td>Adds an empty glyph to every master.</td></tr>
    <tr><th>Duplicate Glyph</th><td>Copies the current glyph under a new name.</td></tr>
    <tr><th>Remove Glyph</th><td>Deletes it from every master.</td></tr>
    <tr><th>Generate Missing Glyphs</th><td>Adds every glyph that the selected coverage filter in the left panel is missing, named and encoded, to every master.</td></tr>
  </tbody>
</table>

Each coverage filter in the left panel shows how many of its glyphs
the font has. Select a filter that is short, then run Glyph → Generate
Missing Glyphs.

</DocSection>

<DocSection title="Name, Unicode, Groups">

The Glyph section of the right panel holds the name, the Unicode
value, the kerning groups, and the Width, LSB and RSB fields.

Unicode values are accepted as `0041`, `U+0041`, or `0x41`.

Renaming updates every place the old name was used: components in other
glyphs, group membership, kerning pairs, the open text session, and the
selection. You do not have to go and fix
references by hand.

Kerning groups and metric keys are covered in
[Spacing and Kerning](/docs/spacing.html).

</DocSection>

<DocSection title="Working in the Grid">

Cmd-click toggles a cell, and shift-click selects a range in the order
shown. Colour marks apply to the whole selection at once. Edit → Copy
Selected Glyphs as Text copies the selection so you can paste a glyph
set somewhere else.

Sort the grid by name or by Unicode value from the View menu, and
narrow it with the search box and filters in the left panel.

</DocSection>

<DocSection title="Related Glyphs">

The Related section of the right panel lists three groups. Click a
name to open that glyph.

<table>
  <caption>Related</caption>
  <tbody>
    <tr><th>Components</th><td>The glyphs it places as components.</td></tr>
    <tr><th>Siblings</th><td>Suffix variants, such as <code>a.alt</code> beside <code>a</code>.</td></tr>
    <tr><th>Used by</th><td>Every composite that places this one.</td></tr>
  </tbody>
</table>

Use it to reach the rest of a family without searching for names.

</DocSection>

<DocSection title="Layers">

The Layers section lists the other masters. Click a row to draw that
master behind the current glyph as a reference.

In the editor, the section also manages named glyph layers. Type a
name in Glyph layer name, then use the buttons.

<table>
  <caption>Layers section</caption>
  <tbody>
    <tr><th>Copy to layer</th><td>Copies the current master's drawing of this glyph into the named layer.</td></tr>
    <tr><th>Remove layer</th><td>Removes the named layer from this glyph.</td></tr>
    <tr><th>Undo layers, Redo</th><td>Undo or redo the last layer change.</td></tr>
  </tbody>
</table>

The Background section is separate. It shows, sends to, swaps with, or clears the UFO `public.background`
layer, which is saved with the font. It can also ghost another glyph
behind the drawing, named by hand.

</DocSection>

<DocSection title="Images and SVG">

<table>
  <caption>Image commands</caption>
  <tbody>
    <tr><th>Place Image…</th><td>Puts a bitmap behind the glyph as a reference.</td></tr>
    <tr><th>Trace Image…</th><td>Converts the placed bitmap into contours, replacing what the glyph holds. Undoable.</td></tr>
    <tr><th>Remove Image</th><td>Takes the bitmap away.</td></tr>
    <tr><th>Import SVG…</th><td>Brings an SVG outline in as contours.</td></tr>
    <tr><th>Export Glyph as SVG</th><td>Writes the current glyph out beside the source.</td></tr>
  </tbody>
</table>
