<DocSection title="Before You Start">

You need Runebender installed and a font to work in. Press
<code>Cmd+N</code> for a new one: an untitled UFO with Google Fonts
metrics and the Latin Core set as empty encoded glyphs. Save it
somewhere you can find it.

<Callout>
  Put the folder under version control first. It costs one command and
  makes every step below undoable.
</Callout>

<CommandList commands={[
  "git init && git add . && git commit -m 'Empty font'",
]} />

</DocSection>

<DocSection title="1. Open a Glyph">

Type `H` in the search box at the top left. Double-click the cell.

The editor opens on an empty glyph with its metrics drawn around it:
the baseline, the x-height, the cap height, and two vertical lines for
the sidebearings.

</DocSection>

<DocSection title="2. Draw the Left Stem">

Take the pen tool.

1. Click at the baseline, a little right of the left sidebearing.
2. Click straight up at the cap height.
3. Click right by about 80 units.
4. Click back down to the baseline.
5. Click the first point again to close the contour.

You have a rectangle. Switch to the select tool and drag its points
until the width looks right at a glance. Numbers come later; the eye
first.

</DocSection>

<DocSection title="3. Reuse It">

Rather than draw the second stem, copy the first: select all four
points with <code>Cmd+A</code>, then <code>Cmd+D</code> to duplicate.
The copy lands on top of the original. Drag it right, holding shift to
keep it level.

Draw the crossbar the same way, a rectangle between the two stems, a
little above the middle. Optically the centre of a letter sits above
the mathematical centre.

</DocSection>

<DocSection title="4. Clean Up">

Three commands, in this order, before you go further.

<table>
  <caption>Cleanup</caption>
  <tbody>
    <tr><th>Path, Remove Overlap</th><td><code>Cmd+Shift+O</code>. Merges the three rectangles into one outline.</td></tr>
    <tr><th>Path, Correct Path Direction</th><td><code>Cmd+Shift+R</code>. Sets the direction the fill rule expects.</td></tr>
    <tr><th>Path, Tidy Up Paths</th><td><code>Cmd+Shift+T</code>. Drops any zero-length segments the overlap left.</td></tr>
  </tbody>
</table>

</DocSection>

<DocSection title="5. Space It">

The bottom bar holds the advance width and the two sidebearings. Set
both sidebearings to the same number to start; something near 80 units
for a capital H at 1000 UPM.

Spacing is judged in company, not alone, which is the next step.

</DocSection>

<DocSection title="6. See It in a Word">

Take the text tool and type `HHH`. Then `HOH` if you have drawn an O,
or leave it as three Hs.

The rhythm should be even: the white inside the H and the white
between two Hs want to look like the same amount of space. Drag the
sidebearing edges until they do. Everything you change shows up in the
line as you change it.

<Callout>
  Nearly all spacing is done this way. A glyph alone tells you almost
  nothing.
</Callout>

</DocSection>

<DocSection title="7. Check the Curves">

Not needed for an H, but do it once now so you know where it is. Open
the Curves section in the right panel and turn on the comb. On
straight segments it is flat. On a letter with curves, a kink that is
invisible at text size shows as a break in it.

</DocSection>

<DocSection title="8. Save">

<code>Cmd+S</code>. The header shows the time.

Now look at what changed:

<CommandList commands={[
  "git diff --stat",
]} />

One glyph file, and the metrics if you touched them. That is the
argument for a source format made of small files.

</DocSection>
