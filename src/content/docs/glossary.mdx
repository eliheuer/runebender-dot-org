<DocSection title="Sources">

<table>
  <caption>Files and formats</caption>
  <tbody>
    <tr><th>UFO</th><td>Unified Font Object. A font source made of directories and files, so it works with version control.</td></tr>
    <tr><th>GLIF</th><td>The XML file that holds one glyph inside a UFO.</td></tr>
    <tr><th>Designspace</th><td>A file that names several masters and the axes between them.</td></tr>
    <tr><th>Master</th><td>One drawn source at a fixed position in the designspace.</td></tr>
    <tr><th>Axis</th><td>A dimension of variation, such as weight or width.</td></tr>
  </tbody>
</table>

</DocSection>

<DocSection title="Drawing">

<table>
  <caption>Outlines</caption>
  <tbody>
    <tr><th>Contour</th><td>One closed or open path in a glyph.</td></tr>
    <tr><th>On-curve point</th><td>A point the outline passes through.</td></tr>
    <tr><th>Handle</th><td>An off-curve control point that shapes the segment beside it.</td></tr>
    <tr><th>Cubic</th><td>A curve with two handles per segment. What UFO and PostScript use.</td></tr>
    <tr><th>Quadratic</th><td>A curve with one handle per segment. What TrueType uses.</td></tr>
    <tr><th>Hyperbezier</th><td>A curve defined by its on-curve points, with the handles solved rather than placed.</td></tr>
    <tr><th>Extreme</th><td>The topmost, bottommost, leftmost, or rightmost point of a curve.</td></tr>
    <tr><th>Path direction</th><td>Which way a contour is drawn. Outer contours and holes must run opposite ways.</td></tr>
    <tr><th>Start point</th><td>The first point of a contour. Masters must agree on it to interpolate.</td></tr>
  </tbody>
</table>

</DocSection>

<DocSection title="Building Glyphs">

<table>
  <caption>Composites</caption>
  <tbody>
    <tr><th>Component</th><td>Another glyph placed inside this one.</td></tr>
    <tr><th>Composite</th><td>A glyph built from components rather than drawn.</td></tr>
    <tr><th>Decompose</th><td>Replace components with copies of their outlines.</td></tr>
    <tr><th>Anchor</th><td>A named point that says where a mark attaches.</td></tr>
    <tr><th>Smart component</th><td>A component that carries its own axes, so one component holds a range of shapes.</td></tr>
  </tbody>
</table>

</DocSection>

<DocSection title="Spacing and Text">

<table>
  <caption>Metrics and shaping</caption>
  <tbody>
    <tr><th>Advance width</th><td>How far the pen moves after drawing the glyph.</td></tr>
    <tr><th>Sidebearing</th><td>The space between the outline and the edge of the advance, left or right.</td></tr>
    <tr><th>Kerning</th><td>An adjustment applied to one pair of glyphs.</td></tr>
    <tr><th>Kerning group</th><td>A set of glyphs that kern alike, so one value covers many pairs.</td></tr>
    <tr><th>Shaping</th><td>Turning characters into positioned glyphs, applying the font's own rules.</td></tr>
    <tr><th>Bidirectional</th><td>Text that mixes directions, such as Arabic with Latin inside it.</td></tr>
    <tr><th>Joining form</th><td>The shape a cursive letter takes by position: initial, medial, final, or isolated.</td></tr>
  </tbody>
</table>

</DocSection>

<DocSection title="Output">

<table>
  <caption>Building a font</caption>
  <tbody>
    <tr><th>Compile</th><td>Turn sources into a font file a system can install.</td></tr>
    <tr><th>fontc</th><td>The Rust font compiler Runebender uses when a project has no build script.</td></tr>
    <tr><th>Production name</th><td>The glyph name that ships, which can differ from the working name.</td></tr>
    <tr><th>Variable font</th><td>One font file that holds a range along its axes rather than a single instance.</td></tr>
  </tbody>
</table>
