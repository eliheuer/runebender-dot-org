<DocSection title="The Application">

[runebender-xilem](https://github.com/eliheuer/runebender-xilem) is the Runebender
application. Xilem describes the interface from application state; Masonry
provides widgets and event handling. The rendering and text stack uses
Linebender libraries.

The repository contains the interface and font operations in one workspace.
Users install one application.

</DocSection>

<DocSection title="Font Operations and Interface">

The interface owns the window, input, and drawing. Font operations belong in
the workspace's library so they can be tested without a window and used by
command-line tools. Moving a point and updating a UFO are font operations;
turning a pointer position into an editing command belongs to the interface.

The file map is on [Code Layout](/docs/code-layout.html).

</DocSection>

<DocSection title="Sources and Documents">

Runebender uses [norad](https://github.com/linebender/norad) for UFO data and
[kurbo](https://github.com/linebender/kurbo) for geometry. Designspaces describe
masters and axes. Font sources remain available to other tools.

A script can work on saved sources; live MCP tools can inspect unsaved editor
state and submit proposals. Coordinate disk writes with the editor. See
[Opening and Saving](/docs/opening.html) and [Agents](/docs/agents.html).

</DocSection>

<DocSection title="Platform Integration">

The desktop application supplies file dialogs, menus, clipboard access, and
file watching. A browser port must supply browser equivalents and verify the
rendering and input path. It is not available yet.

</DocSection>
