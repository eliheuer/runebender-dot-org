<DocSection title="Source and Build">

[runebender-xilem](https://github.com/eliheuer/runebender-xilem) contains the editor and its font engine in the root Cargo package.
The repository pins its Rust toolchain.
Start with its `AGENTS.md`, then use [Code Layout](/docs/code-layout.html) and the [architecture guide](/docs/architecture.html) to find the right module.

```sh
git clone https://github.com/eliheuer/runebender-xilem
cd runebender-xilem
cargo run --release -- path/to/Font.designspace
```

</DocSection>

<DocSection title="Checks">

Use focused checks while iterating and run broader checks relevant to the change before finishing.
The full native CI suite is:

```sh
cargo fmt --all --check
bash .github/scripts/copyright.sh
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo doc --workspace --no-deps --locked
cargo test --workspace --locked -- --test-threads=1
cargo build --workspace --release --locked
cargo deny --locked check advisories
```

The root toolchain is pinned in `rust-toolchain.toml`.
CI runs on Linux and macOS with warnings denied.
Windows has a diagnostic workflow; see [Known limitations](/docs/known-limitations.html).
Some tests need the adjacent Virtua Grotesk checkout or `RUNEBENDER_TEST_FONTS` pointing to a source directory.
Do not count ignored model tests as passing model coverage.

</DocSection>

<DocSection title="Interface Work">

Read the [design principles](/docs/design-principles.html) and [themes](/docs/themes.html) before changing a view.
Use headless captures in Gray and Light for visual checks, then perform native interaction checks when the change needs pointer, keyboard, IME, accessibility, or GPU evidence.
The browser reuses the desktop widget tree; changes that affect it need the checks in the repository's `web/README.md`.

</DocSection>
