<DocSection title="Two Views">

The **grid** shows every glyph in the font as a cell. Browse, search,
filter, select several glyphs at once, and apply colour marks. The
font-wide work is here too: kerning tables, groups, feature code,
colour palettes, font info.

The **editor** shows one glyph with its points, handles, and metrics,
and draws its neighbours around it. You always see a glyph in context
rather than alone on a page.

Double-click a cell to enter the editor. The panels stay in place; the
sections inside them change.

</DocSection>

<DocSection title="Sessions">

The tab strip above the canvas holds several edit sessions. Press the
plus to open another session on the current glyph, and the cross to
close one.

Each session keeps its own text buffer, tool, selection, viewport, and
undo stack. Sessions track a glyph by name, so they survive a rename
and follow you across master switches.

</DocSection>

<DocSection title="Left Panel">

A strip of icons at the top of the panel switches between its sections.
Hover an icon for its name. Axes appears only when the font has a
designspace.

<table>
  <caption>Left panel sections</caption>
  <tbody>
    <tr><th>Glyphs</th><td>The glyph grid, with the search and filter controls below it.</td></tr>
    <tr><th>Shapes</th><td>Reusable shapes to place in a drawing.</td></tr>
    <tr><th>Axes</th><td>The designspace axes and where the current view sits on them.</td></tr>
    <tr><th>Local AI</th><td>Choose a model and run it. See <a href="/docs/local-models.html">Local Models</a>.</td></tr>
  </tbody>
</table>

The Glyphs section holds these controls:

<table>
  <caption>Glyphs section</caption>
  <tbody>
    <tr><th>Search</th><td>Narrow the grid. The controls beside the box set the scope to name, Unicode, or both, and turn on regular expressions and case matching.</td></tr>
    <tr><th>Categories</th><td>Unicode categories: letters, marks, numbers, punctuation, symbols.</td></tr>
    <tr><th>Languages</th><td>Language and script rows with Google Fonts coverage. A row still missing glyphs shows a plus that adds every one it names, encoded, to every master.</td></tr>
    <tr><th>Filters</th><td>Saved filters. Build one from the search controls and keep it; filters are stored in the font, so they travel with the source.</td></tr>
  </tbody>
</table>

View → Sort Glyphs by Name and View → Sort Glyphs by Unicode set the
order of the grid.

</DocSection>

<DocSection title="Bottom Bar">

In the editor, the bottom bar carries the metrics of the current
glyph: advance width and the two sidebearings. Editing a field moves
the outline or the sidebearing directly.

In the grid, it shows the current selection and copies it as text.

</DocSection>

<DocSection title="Header">

The header shows the path of the open font and the state of the file.
After a save it reads the time, so you can tell at a glance whether
what is on screen is on disk.

<Callout>
  Runebender watches the files it has open. Change a UFO on disk with
  another tool, or with a script, and the editor reloads it.
</Callout>

</DocSection>

<DocSection title="Themes">

View → Theme switches the palette. Four themes ship: Dark, Midnight,
Gray and Light. A theme sets more than colour, so corner radii, rule
weights and the way glyph marks are drawn change with it.

See [Themes](/docs/themes.html).

</DocSection>
