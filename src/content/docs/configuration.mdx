<DocSection title="Themes">

`RUNEBENDER_THEME` selects a built-in or installed theme by ID.
`RUNEBENDER_THEME_PATH` adds one theme file or a platform-separated list of files and directories.
The native editor also discovers `.theme.toml` and existing `.theme.json` files in `$XDG_CONFIG_HOME/runebender/themes/`, or `~/.config/runebender/themes/` when that variable is unset.
An unknown theme ID falls back to Gray with a diagnostic.
See [Themes](/docs/themes.html) for the format, installation, and sharing workflow.

```sh
RUNEBENDER_THEME_PATH="$PWD/my-theme.theme.toml" RUNEBENDER_THEME=my-theme runebender
```

</DocSection>

<DocSection title="Local Models">

`RUNEBENDER_MODELS` overrides the local model directory.
Without it, the local model tools use `~/.runebender/models`.
See [Local Models](/docs/local-models.html) for setup and current capabilities.

</DocSection>

<DocSection title="What Is Not a Config File">

Runebender currently does not read the `~/.config/runebender/config.toml` settings previously described here.
Use the documented environment variables and theme files.
For exact available options, inspect the current [application source](https://github.com/eliheuer/runebender-xilem/tree/main/src/application) or run the executable's help command.

</DocSection>
