<DocSection title="Connect to an Open Editor">

The repository root `.mcp.json` declares the client-neutral `runebender mcp --live` command.
The same command can be registered in a client's own settings.
The repository's `.codex/config.toml` mirrors it for Codex in a trusted checkout.
See [MCP](/docs/mcp.html) for setup, session selection, and a read-only first request.

A live connection reads the unsaved canonical document through the native editor.
The browser demo has an in-memory font and does not expose the native Unix endpoint.
`mcp --font` is a separate saved-file workflow.
Neither route grants permission to apply a change merely because a tool is available.

</DocSection>

<DocSection title="Preserve Font Intent">

Keep source files in version control.
Confirm the font, source, glyph name, and any approved reference glyphs before editing.
Across masters, check contour structure, point order and types, start points, component structure, and spacing before accepting a change.
Proof the result at matching scale and in text, then report what was changed and what remains uncertain.

Glyph Grid mark names have semantic meaning and are stored as simple UFO compatibility colors; the active theme chooses how they appear.
Do not infer a designer's review state from a display hue alone.
See [themes](/docs/themes.html) and [file format](/docs/format.html).

</DocSection>

<DocSection title="Current Boundaries">

Runebender is alpha software.
Live receipts are in memory for one document lifetime, so they do not replace saving or version control.
The native editor's live endpoint is Unix-only.
The website's implementation pages may lag a new commit; for exact API names and parameters, use MCP `tools/list` in the connected session and inspect the current source.
See [Known limitations](/docs/known-limitations.html).

</DocSection>
