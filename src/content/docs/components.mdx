<DocSection title="Components">

A component places another glyph inside this one. Edit the base glyph
and every glyph using it follows.

To add one, open the Shapes panel in the left rail. Type the base
glyph name in the Base glyph field and click Add. Select and drag a
component with the select tool. Delete removes it.

Double-click a component to edit its base glyph in place, inside this
glyph. Press Escape, or double-click on empty space, to go back. The
context menu can also open the base glyph in its own tab. The footer
toggle Edit components in place shows the points of every part.

<table>
  <caption>Component commands</caption>
  <tbody>
    <tr><th>Decompose Components</th><td>Glyph menu, or Decompose in the context menu. Replaces every component with its outlines.</td></tr>
    <tr><th>Lock / Unlock</th><td>The Shapes panel, or Enable / Disable Automatic Alignment in the context menu.</td></tr>
    <tr><th>Duplicate / Delete</th><td>The Shapes panel, with a component selected.</td></tr>
  </tbody>
</table>

The Related section of the right panel lists the glyphs this one uses
as components and every composite that uses it, one click away each.

</DocSection>

<DocSection title="Anchors and Auto-Alignment">

An anchor is a named point that says where a mark attaches. A mark
glyph's anchor `_top` attaches to a base glyph's anchor `top`.

Composites align live. Move the anchor on a base glyph and every
accented glyph built from it follows. A locked component follows its
anchors. Click Unlock in the Shapes panel to move it by hand, and Lock
to make it follow the anchors again.

Glyph → Compose from Anchors builds the composites selected in the
overview, or every composite it knows when none is selected.

</DocSection>

<DocSection title="Editing Anchors">

Add Anchor in the canvas context menu adds an anchor at the pointer.
The editor names it automatically: `anchor.0`, `anchor.1`, and so on.
The editor has no field to rename an anchor, so set names in the
source. Select an anchor with the select tool and drag it. Delete
removes it.

Anchor names drive generated feature code. Entry and exit anchors
produce cursive attachment, anchor families produce mark and mark-to-
mark positioning, and `caret_1`, `caret_2` and so on produce ligature
caret positions. See [Feature Code](/docs/features.html).

</DocSection>

<DocSection title="Joining Scripts">

Glyph → Check Joining is for cursive scripts. It measures each positional form's connecting stroke at the joining
edges. Initial and medial join at x = 0; medial and final join at the
advance. It then finds the font's common band and selects every form
that misses it.

See [Text and Shaping](/docs/text.html).

</DocSection>
