<DocSection title="Install Runebender">

Install Rust with [rustup](https://rustup.rs), then install Runebender:

```sh
cargo install --git https://github.com/eliheuer/runebender-xilem
runebender path/to/Font.designspace
```

The package and executable are `runebender`. Run it without arguments to
open the editor. Subcommands such as `runebender info Font.ufo --json`
and `runebender mcp --live` run without opening a window.

Use Rust 1.96 or newer. Runebender opens UFO and designspace sources.
Start without a path to open a font through File → Open.

Runebender is alpha software. Keep your sources in version control.
There is no packaged desktop release yet. Platform prerequisites and
build instructions are in the [repository](https://github.com/eliheuer/runebender-xilem).

</DocSection>

<DocSection title="Build from Source">

```sh
git clone https://github.com/eliheuer/runebender-xilem
cd runebender-xilem
cargo run --release -- path/to/Font.designspace
```

Cargo uses the repository's pinned toolchain. See
[Development](/docs/development.html) for checks and the code layout.

</DocSection>

<DocSection title="In the Browser">

Open the [UI demo](/editor/index.html) to switch between static previews of
the Xilem interface. It does not load, edit, or save fonts.

Use the desktop application for editing. A working browser port is deferred.

</DocSection>
