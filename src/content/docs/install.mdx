<DocSection title="Install Runebender">

Install Rust with [rustup](https://rustup.rs), then install Runebender:

```sh
cargo install --git https://github.com/eliheuer/runebender-xilem
runebender path/to/Font.designspace
```

The package and executable are `runebender`. Run it without arguments to
open the editor. Subcommands such as `runebender info Font.ufo --json`
and `runebender mcp --live` run without opening a window.

Use Rust 1.96 or newer. Runebender opens UFO and designspace sources.
Start without a path to open a font through File → Open.

Runebender is alpha software. Keep your sources in version control.
There is no packaged desktop release yet. Platform prerequisites and
build instructions are in the [repository](https://github.com/eliheuer/runebender-xilem).

</DocSection>

<DocSection title="Windows Status">

The Windows build and headless commands pass basic checks, but the native
application currently crashes during startup in CI. Windows desktop support
is not ready to claim yet.

For development, use 64-bit Windows with Rust's MSVC toolchain. Install the
[Visual Studio C++ prerequisites](https://rust-lang.github.io/rustup/installation/windows-msvc.html),
then use the Cargo install command above.

Open directory-based sources from PowerShell:

```powershell
runebender 'C:\Fonts\Font-Regular.ufo'
```

The Windows file picker currently selects files, so pass UFO, Glyphs Package,
and Babelfont directory paths on the command line. The
[Windows checks](https://github.com/eliheuer/runebender-xilem/actions/workflows/windows.yml)
cover compilation, font inspection, SVG proof, editor rendering, and native
window startup and shutdown; the native check is currently failing.
Editing, dialogs, input methods, and graphics
drivers still need hands-on Windows testing. No installer or ARM build is
available yet.

Live MCP connections and the live chat bridge currently require macOS or Linux.
Headless `info` and `proof` do not need those services.

</DocSection>

<DocSection title="Build from Source">

```sh
git clone https://github.com/eliheuer/runebender-xilem
cd runebender-xilem
cargo run --release -- path/to/Font.designspace
```

Cargo uses the repository's pinned toolchain. See
[Development](/docs/development.html) for checks and the code layout.

</DocSection>

<DocSection title="In the Browser">

[Launch App](/wasm-editor/) to try the real Runebender interface in your
browser. Explore the bundled Virtua Grotesk font, open a glyph, drag outline
points, undo and redo edits, zoom, and resize the panels.

Edits stay in this tab and are discarded on reload. Use the desktop application
to open or save your own fonts and run local AI workflows.

</DocSection>
