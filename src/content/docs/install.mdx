<DocSection title="Install Runebender">

Install Rust with [rustup](https://rustup.rs), then install Runebender:

```sh
cargo install --git https://github.com/fontgarden/runebender
runebender path/to/Font.designspace
```

The package and executable are `runebender`. Run it without arguments to
open the editor. Subcommands such as `runebender info Font.ufo --json`
and `runebender mcp --live` run without opening a window.

Use Rust 1.96 or newer. Runebender opens UFO and designspace sources.
Start without a path to open a font through File → Open.

Runebender is alpha software. Keep your sources in version control.
There is no packaged desktop release yet. Platform prerequisites and
build instructions are in the [repository](https://github.com/fontgarden/runebender).

</DocSection>

<DocSection title="Windows Status">

The Windows build and headless commands pass basic checks, but the native
application currently crashes during startup in CI. Windows desktop support
is not ready to claim yet.

For development, use 64-bit Windows with Rust's MSVC toolchain. Install the
[Visual Studio C++ prerequisites](https://rust-lang.github.io/rustup/installation/windows-msvc.html),
then use the Cargo install command above.

Open directory-based sources from PowerShell:

```powershell
runebender 'C:\Fonts\Font-Regular.ufo'
```

The Windows file picker currently selects files, so pass UFO, Glyphs Package,
and Babelfont directory paths on the command line. The
[Windows checks](https://github.com/fontgarden/runebender/actions/workflows/windows.yml)
cover compilation, font inspection, SVG proof, editor rendering, and native
window startup and shutdown; the native check is currently failing.
Editing, dialogs, input methods, and graphics
drivers still need hands-on Windows testing. No installer or ARM build is
available yet.

Live MCP connections and the live chat bridge currently require macOS or Linux.
Headless `info` and `proof` do not need those services.

</DocSection>

<DocSection title="Build from Source">

```sh
git clone https://github.com/fontgarden/runebender
cd runebender
cargo run --release -- path/to/Font.designspace
```

Cargo uses the repository's pinned toolchain. See
[Development](/docs/development.html) for checks and the code layout.

For an optimized local build that favors shorter rebuilds while working on the UI, use:

```sh
cargo run --profile fast --locked -- path/to/Font.designspace
```

Its first build fills a separate cache, and later builds reuse incremental compilation data.
See [Development](/docs/development.html) for the profile's tradeoffs.

</DocSection>

<DocSection title="In the Browser">

[Launch Application](/wasm-editor/) to try the real Runebender interface in your
browser. Explore the bundled Virtua Grotesk font, open a glyph, drag outline
points, undo and redo edits, zoom, and resize the panels.

In Chrome and Edge, File → Open picks a folder on your computer: a UFO folder,
or a folder that holds one designspace with its UFOs.
Save writes the files back into that folder, and Save As writes into a new one.
You can also drop a folder on the canvas.
The editor keeps the package's own file names, so a saved UFO matches the opened one file for file.
Other browsers keep the bundled font only, and edits there are discarded on reload.
Local AI needs the desktop application.

</DocSection>

<DocSection title="Chromebook">

Runebender runs on a Chromebook as an installed web app.
Chrome gives it a window of its own, an icon in the launcher, and a place on the shelf.
This works on every Chromebook, including managed school and work devices where Linux is turned off.

1. Open [runebender.org/wasm-editor](/wasm-editor/) in Chrome.
2. Click the install icon at the right end of the address bar.
   If the icon is not there, open the Chrome menu, then choose **Cast, save, and share** → **Install page as app**.
3. Click **Install**. Runebender opens in its own window and appears in the launcher.

To remove it, right-click the icon in the launcher and choose **Uninstall**.

The installed app is the browser editor.
It opens the bundled Virtua Grotesk font first.
To work on your own font, choose File → Open and pick the UFO folder, or the folder with your designspace, from the Files app.
Chrome asks once for permission to read and write that folder.
Save writes your changes back to the folder.
An installed app keeps the permission, so the next start reopens the same folder.
Local AI needs the desktop application.
The app renders on the CPU and does not need a GPU, so it runs on low-cost ARM Chromebooks.
It needs a network connection to start.

If your Chromebook can run Linux, you can also build the desktop application.
Turn on Linux in **Settings** → **About ChromeOS** → **Developers**, open the Terminal,
then use the Cargo install command above.
The Linux container is Debian, so install the build packages first:

```sh
sudo apt install build-essential pkg-config libfontconfig-dev libwayland-dev \
  libxkbcommon-dev libx11-dev libxcb1-dev libvulkan1 libssl-dev
```

The build takes about an hour on a Chromebook and needs 8 GB of memory or more.
Installed Linux applications appear in the ChromeOS launcher.
This path is not tested on ChromeOS hardware yet.

</DocSection>
