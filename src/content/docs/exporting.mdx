<DocSection title="Export">

Press <code>Cmd+Alt+E</code>, or use File → Export….

Runebender compiles the font as it is in the editor, unsaved edits
included. It does not save your sources first, and it does not change
them.

The output is `exports/<name>.ttf` in the directory that holds your
source. For `Font.designspace`, that is `exports/Font.ttf`. The footer
says where the file went, or why the export failed.

In the browser, Export downloads the TTF file.

</DocSection>

<DocSection title="How It Compiles">

The compiler is [fontc](https://github.com/googlefonts/fontc), built
into Runebender as a library. You do not install anything. Export does
not run a build script, a separate `fontc` program, or Python.

The live preview uses the same compiler, so the exported font matches
what the preview shows.

<Callout>
  Runebender does not apply production names from
  <code>public.postscriptNames</code>. The glyph names in the exported
  font are the names in your source.
</Callout>

If your project has its own build script, run it yourself to make
release builds.

</DocSection>

<DocSection title="From the Command Line">

`runebender compile` compiles a UFO or designspace with the same
pipeline. It reads the source and does not change it.

<CommandList commands={[
  "runebender compile Font.designspace --out Font.ttf",
]} />

</DocSection>

<DocSection title="Single Glyphs">

Glyph → Export Glyph as SVG writes the current glyph as an SVG file
beside the source. It is for a drawing you want outside the font, not
part of the font build.

</DocSection>
